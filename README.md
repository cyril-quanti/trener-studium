# Trenér – studium

Interaktivní studijní platforma v češtině pro přípravu na ústní zkoušku z trenérského kurzu.

- **Studijní texty** – strukturované poznámky ke každému tématu
- **Kartičky** – opakování metodou Leitner (Umím / Neumím)
- **Simulátor ústní zkoušky** – náhodná otázka z každého zvoleného bloku, vzorová odpověď a kontrolní body

Pokrok se ukládá pouze ve vašem prohlížeči (localStorage).

## Bloky

1. Teorie sportovního tréninku a výživa
2. Etapy tréninku a příprava dětí
3. Právo a sebeobrana
4. Koordinační schopnosti
5. Vytrvalostní schopnosti
6. Regenerace
